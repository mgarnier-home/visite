# Visite — retours n° 1 : plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Appliquer les retours n° 1 : saisie de date française, champs numériques filtrés,
compteur « posées », sélection des pièces à la création avec « Autres questions », case
« Importante » dans le modèle, et nouveau contenu du modèle initial.

**Architecture:** Le back gagne une colonne `important` sur les questions du modèle et un
paramètre d'exclusion de sections à la création de visite, qui regroupe les questions importantes
des sections exclues dans une pièce `topic` « Autres questions ». Le front remplace les champs
numériques natifs par une directive de filtrage partagée et le champ date-heure natif par un
composant Material (date + heure).

**Tech Stack:** Go 1.26.4, SQLite (`modernc.org/sqlite`) ; Angular 22, Angular Material,
`@angular/material-date-fns-adapter`, `date-fns`, Vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-25-retours-1-design.md` (complète
`docs/superpowers/specs/2026-10-25-visite-maison-design.md`).

## Global Constraints

- Branche `feat/retours-1`. Commits autorisés par le propriétaire, Conventional Commits, ligne
  `Co-Authored-By` du modèle qui écrit. Jamais de push.
- Ne pas modifier le port par défaut `3001` de `backend/config.go` ni `analytics: false` de
  `frontend/angular.json` (modifications du propriétaire).
- Code en anglais ; commentaires et interface en français.
- Après ce plan, aucun `type="number"` ni `type="datetime-local"` dans `frontend/src/app`.
- Contrat JSON : `TemplateQuestion` gagne `important: boolean` ; `CreateVisitRequest` gagne
  `excluded_section_ids?: string[]`. Les listes JSON restent `[]`, jamais `null`.
- Pièce « Autres questions » : nom `Autres questions`, kind `topic`, `dir_name`
  `autres-questions` (via `uniqueDirName`), placée juste après la première section `topic` du
  modèle. Texte des questions : `<nom de la section d'origine> : <texte>` (espace avant les
  deux-points).
- Date : `dd/MM/yyyy`, locale `fr` de `date-fns`. Heure : `HH:MM`, 24 h, 00:00 à 23:59. Heure
  vide → 00:00 ; date vide → `visit_at` nul. Valeur envoyée : RFC 3339 avec le décalage local
  (`localIsoWithOffset` de `core/sync.service.ts`).
- Nombres : mode `integer` (chiffres) ou `decimal` (chiffres, un séparateur `,` ou `.`,
  2 décimales au plus) ; vide = `null` ; la valeur envoyée utilise le point.
